# App Name
Drumio

# Goal
A simple web app for drummers to increase their stick control abilities and rudiments

# Platform
Web

# Tech Stack
JavaScript (Vanilla — no framework)
HTML
CSS

# Planned Features
- Metronome (BPM control, beat indicator, multiple sounds, tap tempo)
- Rudiment library (single stroke, paradiddle, and more — data stored in JSON)
- Practice exercises / drills

# Data Storage
No backend or database needed.
All rudiment and drill content will be stored in structured JSON files and rendered dynamically with JavaScript.
User preferences (e.g. dark mode, last BPM) stored in localStorage.

# UI Style
Minimal
Clean
Light and Dark Mode Support

# Rules
Keep components reusable
Keep code modular and maintainable
Keep it simple
No external frameworks or libraries

# Folder Structure
Please follow Web Development best practices
